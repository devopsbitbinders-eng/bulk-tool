# BulkPulse Messenger Tool 🚀

A WhatsApp Business campaign management tool for sending mass notifications via the WhatsApp Cloud API.

## 🌟 Features
- **Facebook OAuth Integration**: Securely connect to your WhatsApp Business Account (WABA).
- **Template Synchronization**: Fetch Meta-approved message templates.
- **Campaign Management**: Upload contacts via CSV/XLSX and launch campaigns.
- **Reporting**: Track Sent, Delivered, and Read statuses.

## 🛠️ Tech Stack
- **Backend**: FastAPI (Python)
- **Database**: SQLite
- **Integration**: WhatsApp Cloud API, Google Sheets API

## 🚀 Deployment
Designed for deployment on **Hostinger VPS** using Nginx and Gunicorn.
